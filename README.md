# coodaa

Portfolio of **Florian Schneider** — Creative Developer & Technical Production Manager from Berlin.

[coodaa.de](https://coodaa.de)

---

## Stack

- [Next.js 15](https://nextjs.org) — App Router
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com)
- [Framer Motion](https://www.framer.com/motion)
- [next-intl](https://next-intl-docs.vercel.app) — DE / EN
- [Vercel](https://vercel.com) — Hosting & Analytics

## Features

- Bilingual (German / English) with locale-based routing
- Dynamic OG images per locale
- JSON-LD structured data (Person + WebSite schema)
- Sitemap & robots.txt
- Accessible — skip link, ARIA labels, semantic HTML

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
